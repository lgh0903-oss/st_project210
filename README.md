# st_project210 - 공공자전거는 일주일 중 어떤 날 가장 많이 이용될까?

## 팀원
- 21004 오윤아
- 21006 이가현

## 질문
"공공자전거 이용량은 정말 요일에 따라 차이가 있을까?"

## 왜 이 주제인가 (팀이 씁니다)
팀이 이 주제를 고른 이유 한 문단.
- 21004 오윤아 : 최근 하교하던 중 횡단보도 주변에 비치된 공공자전거를 자주 발견하면서 이용량에 관심을 갖게 되었다. 그래서 요일과 날짜에 따라 공공자전거의 이용량이 어떻게 달라지는지 궁금해졌고, 공공데이터를활용해 이용 패턴을 분석하고자 주제를 선정하였다.
- 21006 이가현 : 예전에 공공 자전거를 탄 경험이 있다. 근데 엄청 편리하고 빠르게 가서 유용하게 쓴 기억이 있다.그래서 문득 사람들은 어떤날 공공 자전거를 제일 많이 이용하는지 궁금해서 이 주제를 선정하였다.

## 데이터
- 출처(주소):서울 열린데이터 광장- 서울시 공공자전거 따릉이 이용정보(일별)
- 기간·행 수·열 수: 2026.01.01 ~ 2026.06.30 ·2,107,239행·11열
- 사용한 열: 대여일자, 대여소번호, 대여소, 성별, 연령대, 이용건수, 이동거리(M), 이용시간(분)
- 개인 단위 정보 없음 확인: 예

- 출처(주소):기상자료개방포털- 서울 기온분석(일별)
- 기간·행 수·열 수: 2026.01.01 ~ 2026.06.30 ·21행·5열
- 사용한 열: 평균기온(℃), 날짜
- 개인 단위 정보 없음 확인: 예

## 방법
회귀: 공공자전거의 이용량은 요일,날씨,기온등 다양한 요인에 따라 달라질수 있는데 우리의 목적은 어떤 영향을 미치는지 파악하고 특정 조건에 이용량이 얼마나 증가하고 감소하는지 예측하는 것이기 때문에 선정함.
분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜): 
1. 데이터 수집
:데이터를 찾기 위해 노트에 들어가서 서울열린데이터광장에 들어간 뒤 '공공자전거 이용' 키워드로 검색해서 데이터를 수집함.
3. 변수 선택
무엇을: 공공자전거 이용량에 영향을 줄 수 있는 변수를 선택하였다.
어떻게: 날짜, 대여소, 대여구분코드, 연령대, 이용건수 등의 항목을 확인하고, 날짜를 통해 요일을 추가로 구분하였다.
왜: 요일이나 이용자의 특성에 따라 자전거 이용량이 달라지는지 알아보기 위해서이다.
4. 전처리 무엇을: 수집한 데이터의 오류와 불필요한 항목을 정리하였다.
어떻게: 날짜 형식을 통일하고 결측값을 확인하였으며, 날짜별 이용건수를 합산하여 하루 전체 공공자전거 이용량을 구하였다.
왜: 데이터의 정확성을 높이고 회귀 분석에 적합한 형태로 만들기 위해서이다.
5. 분할 무엇을: 데이터를 학습용과 평가용으로 나누었다.
어떻게: 학습용 데이터로 회귀 모델을 학습하고, 별도로 남겨둔 평가용 데이터로 예측 결과를 확인하도록 구성하였다.
왜: 모델이 학습에 사용하지 않은 데이터에서도 정확하게 예측하는지 확인하기 위해서이다.
6. 기준선 무엇을: 다른 모델과 비교할 기준이 되는 모델을 설정하였다.
어떻게: 모든 날짜의 공공자전거 이용량을 학습 데이터의 평균 이용량으로 예측하는 단순한 기준 모델을 사용하였다.
왜: 복잡한 회귀 모델이 단순 평균 예측보다 실제로 더 좋은 결과를 내는지 비교하기 위해서이다.
7. 후보 모델 비교 무엇을: 여러 회귀 모델의 예측 성능을 비교하였다.
어떻게: 선형회귀 등 후보 모델을 학습시키고, 각 모델이 예측한 이용량과 실제 이용량의 차이를 비교하였다.
왜: 어떤 모델이 공공자전거 이용량의 변화를 가장 잘 설명하고 예측하는지 알아보기 위해서이다.
8. 선택 무엇을: 가장 적합한 회귀 모델을 선택하였다.
어떻게: 후보 모델들의 평가 결과를 비교하여 오차가 작고 예측 성능이 좋은 모델을 선택하였다.
왜: 공공자전거 이용량을 보다 정확하게 예측할 수 있는 모델을 찾기 위해서이다.
9. 평가 무엇을: 선택한 모델의 예측 성능을 평가하였다.
어떻게: MAE(평균 절대 오차), MSE(평균 제곱 오차), R²(결정계수) 등의 지표를 활용하여 실제 이용량과 예측 이용량의 차이를 확인하였다.
왜: 모델의 예측이 얼마나 정확한지 객관적인 수치로 확인하기 위해서이다.
10. 해석 무엇을: 회귀 분석 결과를 바탕으로 공공자전거 이용량에 영향을 미치는 요인을 해석하였다.
어떻게: 요일별 이용량 차이와 각 변수의 회귀계수 및 예측 결과를 살펴보았다.
왜: 어떤 조건에서 공공자전거 이용량이 증가하거나 감소하는지 파악하기 위해서이다.
11. 한계 점검 무엇을: 분석 결과의 부족한 점과 한계를 확인하였다.
어떻게: 데이터가 2026년 6월 한 달에 한정되어 있다는 점과 날씨, 기온 등의 변수가 포함되어 있지 않다는 점을 확인하였다.
왜: 분석 결과를 모든 계절이나 장기간의 공공자전거 이용량에 일반화하기 어렵기 때문이다. 향후 날씨와 기온 데이터를 추가한다면 더 정확한 분석이 가능할 것이다.

1. 데이터 수집
무엇을: 서울의 2026년 3월 1일부터 3월 21일까지의 기온 데이터를 수집하였다.
어떻게: 기상자료 데이터를 CSV 파일로 내려받았으며, 총 21개의 행과 5개의 열(날짜, 지점, 평균기온, 최저기온, 최고기온)을 확인하였다.
왜: 날짜에 따른 서울의 기온 변화를 파악하고 미래의 평균기온을 예측하기 위해서이다.
3. 변수 선택
무엇을: 독립변수는 날짜, 종속변수는 평균기온으로 선택하였다.
 어떻게: 날짜를 기준으로 하루가 지날 때마다 숫자가 증가하도록 변환하고, 평균기온을 예측 대상으로 설정하였다.
왜: 날짜가 지남에 따라 평균기온이 어떤 방향으로 변하는지 분석하기 위해서이다.
4. 전처리
무엇을: 날짜와 기온 데이터의 형식을 정리하고 결측값을 확인하였다.
어떻게: 날짜 형식을 통일하고 CSV 파일의 불필요한 안내 문구를 제외하였다. 분석에 필요한 21개 데이터에 결측값이 없는 것도 확인하였다.
왜: 데이터 오류를 줄이고 회귀 분석을 정확하게 진행하기 위해서이다.
5. 데이터 분할
무엇을: 전체 21개의 데이터를 학습용과 평가용으로 나누었다.
어떻게: 앞의 16개 데이터를 학습용으로, 나머지 5개 데이터를 평가용으로 분할하였다.
왜: 과거 데이터를 이용해 회귀 모델을 학습하고, 이후 날짜의 평균기온을 얼마나 잘 예측하는지 확인하기 위해서이다.
7. 기준선 설정
무엇을: 다른 모델과 비교하기 위한 기준선 모델을 설정하였다.
어떻게: 학습 데이터 16개의 평균기온인 약 5.46℃를 계산하고, 평가 데이터 5개의 기온을 모두 5.46℃로 예측하였다.
왜: 회귀 모델이 단순히 평균기온을 예측하는 것보다 더 정확한 결과를 내는지 비교하기 위해서이다.
7. 후보 모델 비교
무엇을: 기준선 모델과 선형회귀 모델을 비교하였다.
어떻게: 두 모델을 이용해 평가 데이터의 평균기온을 예측하고, 실제 기온과 예측 기온의 차이를 비교하였다.
왜: 날짜에 따른 기온 변화 추세를 반영하는 선형회귀 모델이 더 좋은 예측 결과를 내는지 확인하기 위해서이다.
9. 모델 평가
무엇을: MAE, MSE, R²를 사용하여 모델의 예측 성능을 평가하였다.
어떻게: 실제 평균기온과 예측 평균기온의 차이를 계산하여 두 모델의 평가 지표를 비교하였다.
  왜: 모델의 예측 오차가 얼마나 작은지 확인하고 어떤 모델이 상대적으로 더 나은지 객관적으로 판단하기 위해서이다.
10. 결과 해석
- 무엇을: 날짜에 따른 서울의 평균기온 변화와 회귀 모델의 예측 결과를 해석하였다.
- 어떻게: 선형회귀 모델의 기울기를 확인한 결과 하루가 지날수록 평균기온이 약 0.114℃ 상승하는 경향이 나타났다. 또한 선형회귀 모델이 기준선보다 예측 오차가 작다는 것을 확인하였다.
- 왜: 날짜와 평균기온 사이의 관계를 파악하고 기온 변화의 특징을 이해하기 위해서이다.
11. 한계 점검
- 무엇을: 데이터의 양과 분석에 사용한 변수의 한계를 확인하였다.
- 어떻게: 데이터가 21일로 짧고 날짜 이외에 날씨, 강수량, 풍속 등의 변수를 사용하지 못했다는 점을 확인하였다. 또한 두 모델 모두 R²가 음수라는 점을 확인하였다.
- 왜: 짧은 기간의 데이터만으로 장기적인 기온 변화를 정확하게 예측하기 어렵기 때문이다. 앞으로 더 긴 기간의 기온 데이터와 다양한 기상 변수를 추가하면 예측 정확도를 높일 수 있을 것이다.
